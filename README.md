# Gestione Spese Mensili

Applicazione web realizzata in Python utilizzando il framework Streamlit, progettata per facilitare il controllo finanziario personale. Questo strumento permette di gestire lo stipendio mensile, tracciare le uscite e analizzare la distribuzione delle spese attraverso report visuali.

## Live Demo
Puoi utilizzare l'applicazione direttamente online qui:
[https://gestore-spese-mensili-eeyecyrwyiuevf22zlu5xq.streamlit.app/]

## Funzionalità Principali

* **Configurazione Budget**: Impostazione dello stipendio mensile con blocco di sicurezza per evitare modifiche accidentali durante la sessione.
* **Gestione Dinamica delle Spese**: Interfaccia dedicata per aggiungere, modificare o rimuovere voci di spesa con aggiornamento immediato della tabella.
* **Analisi Visiva**: Generazione automatica di un grafico a ciambella che mostra la ripartizione percentuale delle spese rispetto al budget totale.
* **Riepilogo Finanziario**: Calcolo in tempo reale del totale speso e della liquidità rimanente.
* **Esportazione Dati**: Possibilità di scaricare il riepilogo delle attività in formato CSV per un'analisi esterna.
* **Funzione Reset**: Possibilità di azzerare la sessione di lavoro corrente in modo sicuro.

## Tecnologie Utilizzate

* **Frontend/Backend**: Streamlit
* **Data Processing**: Pandas
* **Visualizzazione Grafica**: Matplotlib
* **Linguaggio**: Python 3.x
